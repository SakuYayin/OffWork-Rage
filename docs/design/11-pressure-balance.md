- 单波怪物总数维持最多60，每批最多12只；刷怪间隔从1.35秒逐渐缩短，最低0.65秒。所有生成入口仍有70实体硬上限，精英召唤服从当前波同屏上限。
- 普通怪与Boss出手冷却逐渐缩短，最快为原频率的1.45倍；蓄力、冲刺预警和动作命中点不随此倍率压缩。
- 伤害最高3.6倍、移速最高1.4倍，不再叠加旧版按游戏总时长的额外移速。
- 护甲最多18点：普通伤害除以`1+护甲×0.06`。基础护盾最多为生命的30%，先吸收伤害。真伤跳过护甲与精英减伤，但仍消耗护盾。
- 回复最低45%，经验收入最低60%。回复衰减覆盖回血掉落、持续回复、吸血、升级、商店、事件与跨层回复；经验衰减覆盖普通怪和无尽Boss赠送经验。整数经验四舍五入，原本有经验的普通怪至少保留1点。
- 第1、2波保留入门怪；第3波起出现冲撞和弹幕怪，第6波起引入自爆，第10波起引入护盾和召唤怪；第15波起五种新怪合计70%权重。

Boss生命公式改为`1350×(1+0.38n+min(16,0.012n²))×角色系数`，n为已出现Boss序号减1。前三个Boss血量为1688、1879、2807，第四个3794。实际伤害、移动速度同样随当前波增长。Boss名称、模型、台词和出招读取同一个实体身份，不再借用场地层数。

## 精英词缀

每只精英额外有1.65倍生命、1.15倍伤害，只分配以下一种词缀。

| 词缀 | 真实效果 |
| --- | --- |
| 减伤 | 普通伤害减少28%，与护甲组合结算，至少保留1点有效伤害 |
| 反伤 | 玩家在180范围内命中后，先预警0.35秒，再判定距离与视线；每次最多3点，冷却1.2秒；真伤与BUFF持续伤害不触发，不产生反伤循环 |
| 护盾 | 额外护盾为精英生命的40%；连续3秒没受击后，每秒恢复12%护盾容量 |
| 召唤 | 每4.5秒召唤1只普通怪，每个精英一生最多3只；当前波达到同屏上限时等待 |
| 加速 | 移速额外乘1.3，普通追击速度最多120；冲撞技能仍保留预警和独立冲刺段 |
| 自爆 | 玩家靠近80范围后预警0.7秒；随后在90范围内造成自身伤害1.3倍的一次爆炸，自己死亡 |

## 普通战役

每层Boss从工贼同事、秃头主管、没良心老板和打印机巨兽四种中随机抽取；打印机血量按当前层首领基准的1250/1800缩放，第一层375，第二层764，第三层1250。

怪物池每只独立抽取，新怪在第一、二、三层的总权重分别32%、60%、70%。单波数量随层数、累计清房和房内波次增加，最多28只。普通怪生命、伤害和移速也随上述进度增加，并共享护甲、护盾、精英、回复和经验规则。

## 周序

- 基础射击间隔0.28秒，约每秒3.57轮；所有攻速加成后最快0.16秒，约每秒6.25轮。
- 缓存预热每层增加10%二进制发射频率，最多3层；超频大招频率倍率1.35。
- 单发基础伤害 `12 + 3×漏洞注入 + floor((等级-1)×0.9)`，即子弹随等级成长；漏洞注入满3层再 +9。
- 二进制自带1次穿透，漏洞注入每层再 +1；并行线程仍然按每层多发射1枚。
- 生命80、速度138（原65/128）。改前实测三层区域清怪45秒只有4只、同期女主35只，中期直接失去清场能力，因此上调面板并把伤害接到等级上。
- 单发动作至少0.16秒；站定连续打字循环，不再每次发射重置首帧；移动时优先保留行走动作。
- 弹实体总量上限128。满配超频最多每轮4枚，即最高约25枚/秒，弹体存活1秒。
