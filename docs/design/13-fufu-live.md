# 符符完整玩法接入记录

采用已确认的B方案“糕点三连”。本文件记录真实游戏入口与结算链路，不把素材包或独立状态模块当作角色已经上线。

## 入口与武器

- `Heroes.list`新增第五位角色符符：精力90、移速164、伤害系数1。
- `Game.New("fufu")`立即建立三格满储备，锁定主武器糕点、副武器灯泡；角色、本体和糕点不产生近战普攻。
- 拾取、抽卡、陈旧卡片和商店均使用`Loadout`限制，不能替换武器或添加第三把。伤害、攻速和符符专属强化仍可获得。
- `Game.Burst`对符符改为检查糕点储备，启动0.35秒召唤动作；命中事件才消耗并创建伙伴。此前取消不消耗；成功后至少0.8秒间隔。
- 三格逐格恢复，每格24秒；充能速度BUFF最高3层，每层+12%，间隔最低16秒。

## 伙伴的真实战斗

五种伙伴每次独立20%，允许重复。最多同时三只，第四次移除最早召来的存活伙伴；死亡立即释放位置。保留跨房间生命、身份与召唤顺序，暂停和BUFF页面不推进战斗时间。

| 伙伴 | 基础生命 | 真实攻击 |
| --- | --- | --- |
| 枫叶小猫 | 100 | 三爪，每爪10；一套0.6秒，再休息0.9秒。流血每秒3、持续4秒、最多3层 |
| 水龙龙 | 85 | 一次水流六跳，每跳6，每0.2秒一跳；总1.2秒，之后1.6秒休息。贯穿、潮湿4秒，均不能穿墙 |
| 丹旺旺 | 280 | 不主动攻击；主人身边120范围且有视线时拦截，减伤20%。多只共享1秒拦截冷却，每次只选一只，超出伙伴剩余生命承受能力的原始伤害回落给主人 |
| 普通猫猫 | 90 | 每0.8秒18伤害 |
| 普通狗狗 | 170 | 每1.15秒36伤害，基础单次为猫猫2倍 |

新伙伴前3秒额外减伤30%，与丹旺旺自身减伤组合结算。伙伴使用现有导航追击和跟随，真正拥有生命、受击与死亡状态。

普通敌人可选择最近伙伴作为近战/远程目标；近战动作命中会结算伙伴生命。敌方弹幕使用沿线碰撞，先接触伙伴时扣除伙伴生命并消耗弹体。冲撞、自爆与Boss冲刺也接入伙伴伤害。伙伴短受击间隔0.3秒，避免同一帧连续重复结算。

伙伴输出走`Game.Hit`，吃敌方护甲、减伤和护盾，击杀、金币、经验、连击和无尽分数归属符符。流血使用不递归触发反伤的真伤入口，跳过护甲和正面格挡，仍消耗护盾。低额水流和流血的伤害小数会累计到后续伤害，避免强化后每跳向下取整使增益完全消失。

## 灯泡

真实自动射击间隔1.4秒、射程360，弹体速度340。正常70%／通电20%／闪光10%。

- 正常：12伤害，玻璃碎光。
- 通电：18直接伤害；主目标潮湿时向160范围内最多2个其它潮湿目标逐个连锁，各12伤害，检查视线、不回跳、不递归。
- 闪光：8伤害；普通怪眩晕0.7秒，Boss仅0.2秒，同一Boss4秒内不再受闪光硬直。硬直期间动作计时也停止。

普通、通电和闪光弹具有独立种类字段，不复用订书器弹体表现。专属概率强化从普通占比扣除；满强化时正常45%、通电35%、闪光20%。不会改变伙伴的五种20%概率。

## 渲染和UI接口

- `g.summons`：charges、recovery、cooldown、pets、nextId、interceptCooldown；`g.pets`与其pets引用同一张表。
- pet：id、kind（maple/water/dan/cat/dog）、name、x/y、hp/maxHp、radius、faceX/faceY、moving、animationTime、attackTime、hit、protection。
- `FufuCombat.ChargeInterval(g)`供HUD读取强化后的充能间隔。UI的按钮与按键调用`Game.Burst`，不可仍用旧怒气100门槛禁用。
- 灯泡弹体：`kind="bulb"`，`bulbType="normal"/"electric"/"flash"`，其余沿用真实弹体字段。
- 效果：fufuSummon、fufuClaw、fufuWater、fufuElectric、fufuFlash、fufuGlass、fufuGuard、fufuDepart；字段沿用x/y、life/maxLife、size、angle，水流与连锁另有targetX/targetY。
- 敌方状态：wetTimer、bleedTimer/bleedStacks、stunTimer。渲染不创造伤害、不推进这些时间。

## 回归

`tests.FufuCombat`直接构造真实`Game.New("fufu")`并运行`Game.Update`，验证真实召唤动作、五宠伤害/受击、灯泡、状态、跨房、暂停、掉落和十二项BUFF。另有20000次召唤抽样与10000次实际灯泡生成，检查概率区间。

确定特定宠物/词缀/高生命目标时使用明确夹具；这不是自然通关视频，也不是帧率测量。伙伴上限3、弹体总上限128、每条通电链最多4个次级目标，避免无限密度和递归。

无尽模式额外在清波与击败Boss转入喘息时各触发一次小毯子回复，持续喘息不重复触发；已用真实`Endless.Update`状态转换验证。最新规则回归共9336条通过，包含符符专项118条。
